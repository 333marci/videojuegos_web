Arquitectura Hexagonal

Análisis de estructura, inyección de dependencias y refactorización orientada a dominio.

Resumen Ejecutivo

El sistema backend adopta una Arquitectura Hexagonal orientada a dominio. Este diseño ultra-desacoplado aísla la lógica crítica de negocio de las dependencias externas como bases de datos o frameworks HTTP, mejorando drásticamente el ciclo de desarrollo continuo.

  • Dominio: El núcleo impenetrable. Contiene entidades vitales (Usuario, Videojuego) completamente agnósticas de infraestructura.
  • Aplicación: Casos de uso (Services). Orquesta el flujo de negocio apoyándose en interfaces abstractas.
  • Puertos: Contratos (Interfaces abstractas). Definen cómo debe interactuar la aplicación con el exterior sin conocer su implementación subyacente.
  • Adaptadores: Conectores de frontera (Express Controllers, MySQL Repositories). Traducen el mundo exterior al lenguaje del dominio.

Ventajas Estratégicas

La refactorización hacia puertos y adaptadores rompe la estructura monolítica heredada. Este cambio habilita los siguientes beneficios tácticos:

  • Aislamiento Tecnológico: Flexibilidad inmediata para migrar componentes (ej. cambiar Express por Fastify o MySQL por MongoDB) con impacto CERO en el core del negocio.
  • Maximizando la Testabilidad: La inyección de dependencias facilita la creación rápida de Mocks e In-Memory Repositories para suites de pruebas en Jest, consiguiendo 100% de cobertura sin la fricción de una BBDD real.
  • Comportamiento Predecible: El registro de dependencias a través de un inyector central (dependencies.js) elimina side-effects en memoria.

Mapeo de Módulos

Core Backend (Node.js)

Controllers

Capa HTTP externa. Desempaqueta Request JSON, y empaqueta Response usando códigos HTTP puros. Cero lógica de negocio admitida.

Services

El bastión de reglas tácticas de la empresa. Intercepta ataques, encripta passwords y dicta el ciclo de vida de las plataformas lógicas.

Persistence Adapters

Conductos SQL y FileSystem puros. Serializan y deserializan entidades abstractas para persistirlas permanentemente en disco/motor.

Frontend Architecture

DOM Structure

Index modular, semántico y accesible. Preparado para SEO avanzado y estructuración orientada a Modales sin recargas.

Style Orchestration

CSS Grid y custom properties. Una UI fluida, reescalable dinámicamente según Breakpoints nativos sin librerías de terceros (ej. Tailwind).

State & Fetching

Javascript puro y asíncrono para mutaciones rápidas en el cliente. Interacciones SPA-like y promesas resolviendo contra el backend REST.
